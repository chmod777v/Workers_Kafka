1) пользователь отправляет post запрос на gateway
2) gateway генерирует token
3) gateway идет в бд и записывает token с значением ожидания
4) gateway отправляет кавке запрос с token в топик tasks и получает ответ об успешном получении
5) gateway отправляет ответ пользователю с token
6) worker читает кавку топик tasks
7) worker выбирает сообщение 3-5 секунд
8) worker отправляет кавке {token: ..., message: ...} в топик result
9) gateway читает кавку топик result с {token: ..., message: ...}
10) gateway пишет в бд что по token задача выполнена, message такой-то

1) пользователь отправляет get запрос на gateway с token
2) gateway смотрит redis
3) если данные в redis есть, то отправляет ответ, если нет, то gateway смотрит бд, отправляет ответ и записывает данные в redis
4) если задача готова то отправляет message, если  нет то говорит ждать

понятное дело, что gateway читает кавку паралельно с тем как слушает пользователей и пишет в бд.

в кавке должа быть гарантия Exactly-once
